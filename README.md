## Система учёта платных медицинских услуг

Разработана автоматизированная система для учёта платных медицинских услуг в ГБУЗ НО «Тоншаевская центральная районная больница».

### Модули системы:

1. **ClinicApp** — WPF-приложение для работы с базой данных и API
2. **DatabaseHelper** — модуль подключения и работы с SQL Server
3. **AuthService** — модуль авторизации пользователей
4. **ApiService** — модуль интеграции с внешним API МКБ-10
5. **ValidationHelper** — модуль валидации ввода пользователя
6. **UIService** — модуль отображения сообщений пользователю

### Окна приложения:

| Окно | Назначение |
|------|------------|
| LoginWindow | Авторизация пользователей |
| AdminWindow | Управление врачами, пациентами, услугами |
| DoctorWindow | Просмотр приёмов, оказание услуг |
| PatientWindow | Просмотр услуг, запись на приём |
| AddEditPatientWindow | Добавление/редактирование пациента |
| AddEditDoctorWindow | Добавление/редактирование врача |
| AddEditServiceWindow | Добавление/редактирование услуги с проверкой МКБ-10 |
| BookAppointmentWindow | Запись пациента на приём |
| CompleteServiceWindow | Подтверждение оказания услуги врачом |
